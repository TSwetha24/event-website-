# 🎓 College Event Management Website

A responsive and interactive website designed to manage and showcase college events, including technical symposiums and cultural fests. Built using **HTML**, **CSS**, and **JavaScript**.

## 🚀 Features

- 🎨 Beautiful UI with cards, countdowns, and dark mode
- 🗂️ Categorized events (Tech Symposium - Kriya, Cultural Fest)
- 🗺️ Embedded maps for event locations
- 📥 Google Form integration for event registrations
- 🎤 Voice search (Web Speech API)
- 🧠 AI-based event suggestions
- 🧭 AR-based event navigation (placeholder for future implementation)
- 🔐 Email validation
- 🏆 Gamification with animated badges
- 📊 Real-time local storage metrics
